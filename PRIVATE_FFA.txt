Private OpenBench for the 4PC FFA engine
=======================================

Local only: a copy of repos7/openbench on branch "ffa", with no git remote. Never push it anywhere.
The engine never leaves this machine: the server reads branches from repos7/4pc-ffa-engine with git
and hands each commit to Workers as a zip (/clientGetSource/...), guarded by the token in
Config/credentials.ffa_engine (the same token is in Client/credentials.ffa_engine).

Start
-----
1. start_server.bat   -> http://127.0.0.1:8000  (user anurag2801, password in .local_password.txt;
                         change it under Profile)
2. start_worker.bat   -> plays the tests (-T 6 = 6 games at once; edit the file to change it)
Every page needs a login, and only an admin can create accounts.

Tests
-----
Create Test: engine ffa_engine, source local:C:/Users/dell3/source/repos7/4pc-ffa-engine (filled in).
- Dev/Base branch: any branch, tag or commit of the engine repo. Its commit message needs "Bench: N".
- A/B of an option on the same commit: same branch for both, and the option in Dev Options only,
  e.g. "Threads=1 Hash=16 EvalMobility=100".
- Dev and Base must use the same time control. Default 4.0+0.04, bounds [0, 10], book
  ffa_human_ply8.txt, 1v3 seating (Dev in every seat once per group of 4 games).
- Statistics are those of tools/ffa_match.py: one sample per group (pairwise placement score),
  GSPRT with the normal approximation, no verdict before 20 groups. "Pairs" are Dev-seat vs
  Base-seat placements; "places" are Dev's finishing places.
- Priority (higher runs first) and Throughput (share among tests of the same priority) can be
  changed on a running test, and tests can be stopped and resumed from their page.

Time controls scale with the bench speed: the engine's reference NPS is 440000, the laptop's bench
with 6 games running. Update Engines/ffa_engine.json and run
  python manage.py import_engines Engines/ffa_engine.json
if that changes (new engine speed, other machines).

Tablet (later)
--------------
Start the server on 0.0.0.0:8000 (edit start_server.bat; Windows may ask to allow Python on the
private network), copy Client/ with credentials.ffa_engine to the tablet, and run client.py there
with -S http://<laptop's LAN IP>:8000 --no-client-downloads. The engine needs a bigger search-thread
stack on Android first (see the engine's ISSUES.txt).
